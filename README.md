# ร้านซ่อมเว็บ Simulator

เกมเรียนรู้ภาษา HTML สำหรับนักเรียนชั้นมัธยมศึกษาปีที่ 3 ผู้เล่นเป็นช่างฝึกหัดของเฮียแท็กในร้านซ่อมเว็บ รับลูกค้าที่เดินเข้าร้าน อ่านปัญหาของเว็บ แล้วแก้โค้ด HTML ให้ตรงกับที่ลูกค้าต้องการ

**เล่นได้ที่:** https://ชื่อผู้ใช้.github.io/webfix-shop-simulator/

## วิธีเล่น

- เดินด้วยปุ่มลูกศรหรือ WASD กด E หรือ Space เพื่อคุยหรือใช้ของ
- คุยกับลูกค้าที่เคาน์เตอร์เพื่อรับงาน แล้วเดินไปที่คอมหลังร้านเพื่อแก้โค้ด
- โต๊ะซ่อมเว็บมี 3 ช่อง: ใบสั่งงาน (เช็กลิสต์ตามโจทย์), โปรแกรมแก้โค้ด (ไฮไลต์แท็กและเครื่องสแกนไวยากรณ์) และเบราว์เซอร์จำลองที่แสดงผลทันที
- ส่งงานได้เมื่อครบตามโจทย์และไวยากรณ์ถูกต้อง ได้ค่าจ้าง ดาว และชื่อเสียง
- เรียนแท็กใหม่ได้ที่สถาบันช่างแท็ก เก็บเงินอัปเกรดและขยายร้าน

## เนื้อหาในเกม

- บทเรียน 8 บท: p, h1–h6, strong/em, ul/ol/li, a href, img, table และโครงสร้างเว็บเพจ
- งานซ่อม 34 แบบ: งานเนื้อเรื่อง 8 งาน และงานด่วน 26 แบบที่สุ่มร้านและข้อมูลใหม่ทุกครั้ง
- การ์ดแท็ก 18 ใบ ควิซ และแท็กหลงทางในเมือง
- ระบบเสริม: ตกปลา 13 ชนิด ตลาดนัด ร้านไอที เลี้ยงแมว โจรขโมยของ สภาพอากาศ และกลางวันกลางคืน
- เพลงประกอบ เสียงเดินตามพื้น เสียงคีย์บอร์ดตอนพิมพ์โค้ด และเมนูตั้งค่าเสียง

## เทคโนโลยี

- HTML, CSS และ JavaScript ไฟล์เดียว (index.html) ไม่ต้องติดตั้งอะไรเพิ่ม
- กราฟิก 3D วาดด้วย WebGL เสียงและเพลงสร้างด้วย Web Audio API
- บันทึกความคืบหน้าไว้ในเบราว์เซอร์ (localStorage)
- แนะนำให้เล่นบนคอมพิวเตอร์ด้วย Chrome หรือ Edge
